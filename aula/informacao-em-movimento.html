informação de um lugar
pro outro — e, no meio

Sintaxe, framework, paradigma: tudo isso é detalhe de como essa movimentação acontece. O princípio, reduzido ao osso, é só esse.

entrada → transformação → saída

Três papéis, três níveis de controle

Quanto cada camada pode realmente fazer com a informação.

HTML
descreve o que existe
CSS
descreve como aparece
JS
é onde você escreve a decisão

HTML: informação estática

O que você escreve é exatamente o que existe — sempre, até outra coisa mudar isso.

<button id="comprar">Comprar</button>
esse botão não faz nada sozinho, hoje, amanhã, nunca

CSS: reação fechada

Existe uma fresta de reação — :hover, :focus, @media — mas é um conjunto pré-definido de gatilhos, não uma lógica que você escreve.

isso é só CSS — nenhuma linha de JS envolvida

JS: onde você escreve a lógica

Aqui a informação vira variável: pode ser lida, testada, guardada, combinada. JS não decide nada sozinho — é só a ferramenta. Quem decide é quem escreve o código, e isso depende muito mais de entender o problema do que de saber sintaxe de cor.
