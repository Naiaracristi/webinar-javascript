Algoritmos

Conceito

Um algoritmo é uma sequência de passos bem definidos para resolver um problema. Assim como uma receita de bolo diz exatamente o que fazer e em que ordem, um algoritmo descreve as instruções que um programa deve seguir.

Exemplo
1. Pegar dois números 2. Somar os dois números 3. Mostrar o resultado

Variáveis

Conceito

Uma variável é um espaço na memória do computador que guarda um valor, como um número, um texto ou um resultado. Esse valor pode mudar ao longo da execução do programa — daí o nome "variável".

Exemplo
let idade = 25; let nome = "Maria";

Condicionais

Conceito

Condicionais são estruturas que permitem ao programa tomar decisões: "se isso acontecer, faça aquilo; senão, faça outra coisa". É assim que um programa consegue reagir de formas diferentes dependendo da situação.

Exemplo
if (idade >= 18) { console.log("Maior de idade"); } else { console.log("Menor de idade"); }
